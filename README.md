# WS 牌組管理器 — Android

> **非官方粉絲專案**，與 Bushiroad 及各原作品權利方無任何關聯，非商業用途。

Weiß Schwarz（ヴァイスシュヴァルツ）集換式卡牌的牌組管理 App。用手機下載安裝即可使用，不用透過應用商店。

## 安裝教學

1. 用手機瀏覽器（或先在電腦上下載再傳到手機）打開 [Releases 頁面](https://github.com/lungmark0618-collab/WSDeckBuilder-android/releases/latest)。
2. 點最新版本下面的 **Assets**，展開後點 `app-release.apk` 下載。
3. 下載完成後，從手機的「通知」或「檔案」App 點開這個 APK 檔案準備安裝。
4. 第一次安裝會跳出「不允許安裝不明來源的應用程式」的警告——這是正常的，因為這個 App 不是從應用商店裝的：
   - 點警告訊息裡的「設定」，把你用來下載/開啟這個檔案的 App（瀏覽器或「檔案」）的「允許安裝不明應用程式」打開。
   - 每支手機的畫面用詞可能略有不同（例如「安裝未知應用程式」「未知來源」），意思都一樣，回上一頁再點一次 APK 檔案繼續安裝就好。
5. 安裝完成後即可開啟使用。之後官方出新卡表或 App 有新版本，App 內都有「檢查更新」可以直接更新，不用每次都回來重新下載安裝。

## 更新

- **卡表資料**：設定分頁「檢查更新」，抓最新卡表，不用重新安裝 App。
- **App 本身**：有新版本時 App 會自動提示，點了會直接下載新的 APK 幫你完成安裝；也可以隨時回到上面的 Releases 頁面手動抓最新版。
