# WSDeckBuilder Android 介面同步

與 iOS 共用設計方向：克制的展示感、石墨灰及淡色表面、清楚的標題、讓真實卡面成為焦點。文字、面板與導覽均隨背景切換。

## 本次修改

- 首頁保留商品大圖輪播與最新動態；沒有「最新商品／值得期待」宣傳標題。商品圖使用 Fit 完整呈現，圖片與標題分區。輪播維持手動切換。
- 常用牌組不再依賴新聞成功載入。載入中、空資料、全部分類隱藏各自提供對應提示。
- 保留原有新聞搜尋與分類篩選。消息列表改為細分隔線與文字層次。
- 圖鑑增加頂部「全部卡片」入口與系統返回支援，作品卡片使用淡色調、兩行名稱與 48 dp 收藏按鈕；選作品階段隱藏編輯牌組工具。
- 牌組頁有清楚的建立入口、空白狀態建立／QR 匯入按鈕、牌組總數與 CX 張數；保留 Android 原生的釘選和更多選單。
- 底部分頁改為自適應寬度、中性選取色與可存取的 Tab 選取語意。AI 浮動按鈕降低亮度。
- 設定 → 外觀 → 背景：跟隨系統、淺色、深色、純黑、米紙、深海藍、自訂顏色。
- 自訂背景提供六位色碼與 RGB 滑桿，保存至偏好設定；無效色碼不會覆蓋已儲存的顏色。
- 暖白／冷灰文字也會區分明暗模式。Android 系統狀態列圖示隨背景調整。

## 驗證範圍

配色測試涵蓋系統明暗、強制風格、自訂色保真、主要文字對比與設定持久化。建置與測試結果以交付紀錄為準。

目前桌面自動化無法連接 Android 模擬器，因此尚未完成 Android 畫面與大字級的人工視覺驗證。iOS 已檢視米紙背景的外觀頁、圖鑑及保留大圖的首頁。
